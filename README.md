# 🚀 Hammad Qureshi — Portfolio

Award-winning personal portfolio built with React, Three.js, Framer Motion, and TailwindCSS.

## ⚡ Tech Stack

- **React** + **Vite** — Fast dev environment
- **TailwindCSS v4** — Utility-first CSS
- **Framer Motion** — Buttery-smooth animations
- **Three.js** + **React Three Fiber** — 3D decorative elements
- **Lenis** — Smooth inertia scrolling
- **Lucide React** + **React Icons** — Icon libraries

## 🛠️ Setup

```bash
# Clone the repo
git clone https://github.com/Hammad-xureshi/portfolio.git
cd portfolio

# Install dependencies
npm install

# Start dev server
npm run dev

# Build for production
npm run build
```

## 📁 Key Directories

```
src/
├── components/     # All React components
│   ├── layout/     # Navbar, Footer
│   ├── sections/   # Hero, About, Skills, Projects, CTF, Journey, Certs, Contact
│   ├── ui/         # Reusable UI components
│   └── three/      # Three.js 3D components
├── data/           # portfolioData.js — edit this to update content
├── hooks/          # Custom hooks
└── styles/         # Global CSS
```

## ✏️ How to Update Content

All portfolio content lives in `/src/data/portfolioData.js`. Edit that single file to:
- Update personal info, social links
- Add/remove projects, CTFs, certifications
- Edit timeline/journey milestones
- Change skills and categories
